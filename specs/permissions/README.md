# Capability permissions

An app declares requests as `{ "capability": "network.request", "scopes": ["https://api.example.com/weather"] }`. Beta capability names are ai.generate, network.request, file.read, file.write and notification.show. Scopes must be nonempty. Requests are data and never grants. `HostGrant` is constructed by trusted host code and is intentionally not deserializable from an App Definition. The `ai.generate` capability authorizes the host's `default` provider profile without granting arbitrary HTTP access.

The host separately approves grants. The desktop flow first validates a definition and returns an opaque review token, then constructs grants only for user-selected requested scopes. The resolver intersects grants with requests and evaluates the resolved operation input immediately before execution. Missing grants, a grant for another app, target type mismatches and malformed scopes fail closed. Internal state writes and clock reads also cross the resolver as app-local effects.

Network scopes are HTTP or HTTPS origins plus path prefixes. Scheme, normalized host, effective port and a whole path segment must match; query strings do not widen authority, and credentials, fragments, encoded separators and wildcards are rejected. Redirect destinations require a new decision when HTTP transport is added in Phase 6. File scopes name existing canonical directories. Read targets are canonicalized, and write targets require a canonical existing parent, which blocks traversal and symlink escapes. The file adapter must still open files defensively because path authorization and opening are separate system calls.

Operation definitions advertise required capabilities, and app validation rejects workflows that fail to request them. `http.request`, `notification.show` and `ai.generate` are checked before reaching their host adapter. File capabilities are available to connector operations introduced later. Renderer resources remain host handles; remote resource resolution will use the same network resolver in Phase 6.
